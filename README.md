# FUCHS-CSC Cluster ML Pipeline: Rural Road Detection

This repository contains the production-ready Python pipeline and Slurm batch scripts for training and tuning Random Forest models (**M5, M6, and M7**) on Goethe University's **FUCHS-CSC High-Performance Cluster**.

---

## 1. What Goes Where: The Golden Rule for Beginners

When working with High-Performance Computing (HPC) and Git, always follow this distinction:

| Asset Type | Examples | Destination | Transfer Method | Why? |
| :--- | :--- | :--- | :--- | :--- |
| **Code & Configs** | `.py`, `.sbatch`, `.gitignore`, `requirements.txt`, `README.md` | **GitHub** $\rightarrow$ **FUCHS `$HOME`** | `git push` / `git pull` | Lightweight text files. Version controlled. |
| **Datasets** | `*.parquet` (34.8 GB), `*.shp`, `*.dbf`, `*.tar` | **FUCHS `/beegfs/project/`** | **WinSCP / SFTP / `scp`** | **NEVER Git!** GitHub has a 100 MB file limit. |
| **Python Envs** | `venv/` | **Build directly on FUCHS** | `python -m venv` | Platform-specific binaries (Windows $\neq$ Linux). |
| **Trained Models & Logs** | `*.joblib`, `*.out`, `*.json` | **FUCHS `/beegfs/project/results/`** | Generated by Slurm jobs | Large binary checkpoints. Stored on BeeGFS. |

## 5. Running the Pipeline on FUCHS-CSC

### Step 1: Create the Cluster Python Virtual Environment
On FUCHS:
```bash
module load python/3.11
python -m venv /beegfs/project/road_ml/venv
source /beegfs/project/road_ml/venv/bin/activate
pip install -r requirements.txt
```

### Step 2: Verify Data & Schema Contract (Interactive Test)
Before submitting a multi-hour batch job, verify data access and the schema resolver inside an interactive allocation:
```bash
salloc --partition=fuchs --nodes=1 --ntasks=1 --cpus-per-task=4 --mem=16G --time=00:30:00

# Inside the interactive session:
python -c "
from pathlib import Path
from src.config.config import MODEL_FEATURE_REGISTRY
from src.data.loader import load_harmonized_national_dataset, load_ground_truth_labels

shp = Path('/beegfs/project/road_ml/data/shapefiles/DistrictRoads_with training data.shp')
labels = load_ground_truth_labels(shp)
roads = set(labels['road_id'].unique())
features = MODEL_FEATURE_REGISTRY['m5']
df = load_harmonized_national_dataset(Path('/beegfs/project/road_ml/data/parquet_national'), features, roads)
print(f'Verification SUCCESS: Ingested {len(df):,} rows with {len(df.columns)} harmonized columns.')
"

exit
```

### Step 3: Submit Slurm Batch Jobs

* **Option 1: Full Monolithic 5-Fold Cross-Validation (M5)**  
  Runs all 5 folds sequentially on 1 node using 20 Xeon cores and 120 GB RAM:
  ```bash
  sbatch slurm/train_m5_monolithic.sbatch
  ```

* **Option 2: 5-Node Parallel Array Job (M5) — 5x Faster**  
  Submits 5 jobs simultaneously across 5 separate cluster nodes (each node solves 1 fold):
  ```bash
  sbatch slurm/train_m5_array.sbatch
  ```

* **Option 3: Hyperparameter Optimization (Optuna Bayesian TPE)**  
  Runs 50 trials across 20 cores exploring tree depth, min samples leaf, and split criteria:
  ```bash
  sbatch slurm/tune_rf_optuna.sbatch
  ```

### Step 4: Monitoring & Output Validation
```bash
# Check queue and running job status
squeue -u $USER

# Post-job performance and memory audit
sacct -j <job_id> --format=JobID,JobName,Partition,AllocCPUS,Elapsed,MaxRSS,ReqMem,State,ExitCode
seff <job_id>
```

Output models, predictions, and evaluation metrics will be saved in:  
`/beegfs/project/road_ml/results/`  
Logs (stdout/stderr) are stored in:  
`/beegfs/project/road_ml/logs/`

## 6. Built-in HPC Safeguards

1. **NUMA Interleaving (`numactl --interleave=all`)**: Evenly distributes the 80+ GB memory buffer across both processor sockets, avoiding memory bus choking.
2. **Linear Algebra Thread Clamping (`OMP_NUM_THREADS=1`)**: Prevents BLAS/OpenMP from spawning 20 threads *inside* each of the 20 worker trees (which would crash the node via a 400-thread thrashing storm).
3. **Local SSD Scratch (`/localscratch/$SLURM_JOB_ID`)**: Redirects all intermediate caching and `joblib` memory maps off `/dev/shm` and onto the local 1.4 TB NVMe SSD, preventing out-of-memory kernel panics.
4. **Master Schema Contract (`src/data/loader.py`)**: Automatically detects and imputes the 44 missing columns in desert regions (e.g. Otjozondjupa) with `0.0`, eliminating the PyArrow crash.
